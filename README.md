# WaravutVisual GitHub Pages site

A standalone static website for WaravutVisual and G23 Evidence Copilot.

## Files
- `index.html` — page content and metadata
- `styles.css` — responsive visual styling

## Publish with GitHub Pages

Recommended: publish this site from a **separate repository** so the G23 application repository remains untouched.

1. Create a new public repository named `WaravutVisual.github.io` under the `WaravutVisual` account.
2. Upload `index.html`, `styles.css`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub Pages reports the deployment as successful, visit `https://waravutvisual.github.io/`.

Do not report the site as published until GitHub Pages confirms a successful deployment and the URL loads.
